
# Specific PowerShell information

At one time, all [Windows](cs-os-windows.md) back-end adminstration was with the command prompt with MS-DOS.

However, now everything is done via PowerShell. It's far more powerful, though the syntax is often less intuitive. In some ways, it feels like what would happen if Java's committee tried to adapt bash.

However, MS-DOS batch and script files are still useful in edge cases, at least for smaller tasks.
