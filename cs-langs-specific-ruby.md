
# The Ruby programming language

Ruby itself was created in 1993 as a general-purpose language. It has most of the features of other languages like Python or JavaScript.

- However, Ruby treats *everything* like an object, and its designer wanted that because Python was simply not object-oriented enough for his taste.

The more popular implementation of Ruby, however, is Ruby on Rails, which is designed to give "rails" to prevent programmers from doing stupid things.

- The irony of this approach is that [expert developers](cs-habits.md) actually *try* to [hack](mind-creativity-hacking.md) things together, which means Ruby on Rails can actually work *against* their workflow.
